# 📊 Amazon Reviews — Análise de Sentimentos

## 🧠 Sobre o Projeto

Este projeto realiza uma **análise de sentimentos em avaliações de produtos da Amazon**, utilizando técnicas de **Processamento de Linguagem Natural (NLP)** e **Machine Learning** com Python. O objetivo é classificar automaticamente as reviews em **sentimentos positivos ou negativos**, extraindo insights relevantes a partir de textos reais de usuários.

Este projeto faz parte do meu desafio pessoal de desenvolver **22 projetos de Machine Learning**, do nível básico ao avançado, com foco em aplicações práticas.

---

## 📌 Estrutura do Projeto

- 📘 `Amazon_reviews.ipynb` — Notebook principal do projeto  
- 📂 Etapas de pré-processamento de texto  
- 🤖 Treinamento e avaliação de modelos de Machine Learning  
- 📈 Análise de métricas e visualização dos resultados  

---

## 🛠 Etapas Desenvolvidas

1. Carregamento e exploração do dataset de reviews da Amazon  
2. Limpeza e pré-processamento do texto  
   - Remoção de stopwords  
   - Normalização  
   - Tokenização  
3. Extração de características textuais (vetorização)  
4. Treinamento de modelos de classificação de sentimentos  
5. Avaliação dos modelos utilizando métricas de desempenho  
6. Visualização e interpretação dos resultados  

---

## 📊 Resultados

- Classificação automática de sentimentos **positivos** e **negativos**
- Avaliação de desempenho com métricas como:
  - **Acurácia**
  - **loss**

Os resultados demonstram a eficácia do modelo em identificar o sentimento predominante nas avaliações dos usuários.
